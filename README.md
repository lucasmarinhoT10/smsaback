## Descrição

`smsaback` é um middleware para gerenciamento de logs e endpoints, facilitando a integração e monitoramento de aplicações.

## Instalação

Requisitos:
- Python >= 3.9
- PDM >= 2.25

Para instalar as dependências, utilize:
- rode o comando `pdm install`
